## Slider–Crank Mechanism

## Mechanism Design, Kinematic Analysis, and Prototyping

This repository documents the design and ongoing analysis of a **Slider–Crank Mechanism**. The project aims to integrate analytical kinematics, position, velocity, and acceleration analysis, multibody simulation, and physical prototyping using 3D-printed resin components.

The mathematical model, simulation, and physical model will use consistent geometry and operating conditions once rotational speed (RPM) and initial crank angle are finalized.

## Hardware Design with Fusion 360

The physical prototype is designed for **3D resin printing** at **300% scale** (three times the original CAD design).

| Parameter | Design value |
| --- | ---: |
| Crank radius, r | 45 mm |
| Connecting rod length, L | 90 mm |
| Offset, e | 0 mm (pending verification) |
| Slider stroke, S | 90 mm |
| Frame width | 210 mm (approx.) |
| Frame depth | 100.95 mm (approx.) |
| Frame height | 97.5 mm (approx.) |

Link lengths are measured **center-to-center**. Dimensions are based on the scaled design and **have not yet been verified against the printed physical model**.
